# REWRITE

Mục tiêu: viết lại đoạn dưới theo technical academic style.

Input:
[PASTE TEXT]

Giữ nguyên:
- facts;
- số liệu;
- citations;
- scope;
- meaning.

Được phép:
- đổi cấu trúc câu;
- gộp/tách câu;
- sửa thuật ngữ;
- loại bỏ filler;
- làm rõ điều kiện.

Không được:
- thêm facts;
- thêm citation;
- đổi số liệu;
- biến inference thành fact.

Output:
1. Revised text
2. Changed claims / risk flags
3. `[CẦN KIỂM CHỨNG]` nếu có.
